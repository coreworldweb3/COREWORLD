# Notion学習コース：第1回配信

## 基準と実装範囲

2026年10月12日にユーザーが提供した案内文と画像を基準にしています。
全7回・計165分で、AIのみ／Notion／Google Sheetsを比較します。
今回はコース案内の投稿と第1回の教材・演習・模範解答を実装しました。
第1回の会議メモ・演習・解答は、提供された構成に沿って今回具体化したものです。
画像と同じ進捗表示、進捗の永続保存、自動採点、評価シートの入力画面、第2～7回の配信は未実装です。

## 操作

1. Botを起動し、コマンド同期とログイン成功を確認します。
2. サーバー管理権限を持つ人が、投稿先の通常テキストチャンネルで `/notion-course` を実行します。
3. 全7回の案内と「第一回の学習を始める」ボタンが、そのチャンネルに公開されます。
4. 参加者がボタンを押すと、本人だけに第1回の教材、CSV、解答ボタンが表示されます。
5. 手元の対話型AIで演習し、「模範解答・理解度チェック」で答え合わせします。

Botは学習用のAIを呼び出しません。今回の機能にAPIキーやNotion連携は不要です。
学習用データは架空で、既存のSQLite DB・Trelloデータは変更しません。
コマンドを実行するたびに新しい案内が投稿されます。自動投稿はありません。

## 権限と再起動

案内投稿は「サーバー管理」権限を実行時にもチェックします。
Botには投稿先の「チャンネルを見る」「メッセージを送信」「埋め込みリンク」「ファイルを添付」権限を付与します。
開始ボタンは固定custom_idとtimeout=Noneで登録し、setup_hookでadd_viewします。
同じBotとこのコードを再起動すると、既存の案内の開始ボタンが再び使えます。
本人向けの解答ボタンは15分で期限切れになり、Bot再起動時にも失効します。
失効した場合は公開案内の開始ボタンをもう一度押します。

## Windowsでの起動と確認

現在のBotを止めてから、変更したコピー先で起動します。同じBotを二重起動しないでください。
元のGドライブ側には今回の変更は反映されていません。

このコピー先には仮想環境と必要なライブラリを導入済みです。
停止後は `C:\Users\yumen\Documents\Codex\COREWORLD\run_bot.cmd` をダブルクリックするか、次を実行します。

```powershell
cd 'C:\Users\yumen\Documents\Codex\COREWORLD'
.\run_bot.cmd
```

run_bot.cmdは環境を有効化しなくても起動できます。今回の実行環境でアクセス不能だった
継承SSLログ出力先を解除して起動します。TLS証明書の検証は有効のままです。

通常のPython環境で、PowerShellから次を実行します。

```powershell
cd 'C:\Users\yumen\Documents\Codex\COREWORLD'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\main.py
```

pythonコマンドが使えない場合は、利用中のPython実行ファイルを指定してください。
.envはコピーされたものを利用し、トークン値をチャットやGitに出さないでください。
起動時のコマンド数は今回の構成では11です。

動作確認項目：

- `/notion-course` の公開投稿と、本人向けの投稿完了通知
- ボタンで第1回の教材・3案件のCSVが表示されること
- 解答ボタンが機能し、別の参加者にも教材が表示されること
- Bot再起動後に、同じ公開案内の開始ボタンが機能すること
- `/task-list` など既存コマンドが動くこと
- サーバー管理権限のない人が案内を投稿できないこと

テストは通信なしで実行できます。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 戻す場合

Botを止め、元のGドライブ側のコードで起動すると今回の追加前に戻ります。
新しい案内の開始ボタンは旧コードでは反応しないので、その案内メッセージは削除してください。
変更済みのコマンド一覧は、起動時の既存のギルド同期で更新されます。
