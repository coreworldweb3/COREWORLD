# CORE WORLD 活動紹介Webサイト

依存パッケージを必要としない静的サイト。Node.js 18以上で生成できます。

## 起動

```powershell
cd website
node scripts/build.mjs
node scripts/check.mjs
node scripts/test-interactions.mjs
node scripts/serve.mjs
```

`http://127.0.0.1:4173` を開きます。終了は Ctrl+C。

## 更新する場所

- `content/site.json`：プロジェクト・活動ログ・年表・アイデア・ロードマップ・公開連絡先。
- `src/styles.css`：デザイン・スマートフォン対応。
- `src/app.js`：検索・絞り込み・モバイルメニュー。
- `scripts/build.mjs`：全ページ生成。1件のプロジェクト追加で一覧と詳細・状況一覧を生成。

プロジェクトの `id` は小文字英数字とハイフン。状態は「実施済み」「開発中」「検証中」「企画中」「将来構想」のいずれかです。`source` には根拠を記録します。根拠欄は公開HTMLに出力しません。ただし公開リポジトリのソース自体は閲覧可能なので、個人情報や非公開資料本文は記載しないでください。

## 公開前確認

公開承認済みの初期版は `publication: "published"`。確認用に戻す場合は `preview` を設定すると全ページに確認用表示とnoindexを付けます。**noindexはアクセス制御ではありません。** 公開サーバーや公開リポジトリにアップロードした内容は閲覧され得ます。

- 組織情報、掲載範囲、活動の状態・日付を本人と確認。
- メール・Discord・SNSは実際の連絡先を載せず「準備中」。GitHubはリポジトリにリンク。実際のメール・SNSを追加する場合は公開許可を確認。
- さかさ川楽市の名称・日付・会場・全体開催時間は提供チラシで確認済み。体験ブースの時間・料金・参加方法は未確認。
- 写真は未使用。追加する場合は使用許諾・写り込む人の公開可否・代替テキストを確認。
- GKTや個人プロジェクトをCORE WORLDの傘下・公式実績として扱わない。
- 公開先決定後に `publication` を `published` へ変更して再ビルド。

問い合わせの送信機能、Discord連携、英語版は未実装です。メール設定時はmailtoリンク、外部URL設定時は外部リンクとして表示します。アクセス解析・外部フォント・外部画像・Cookieは使用していません。

## 配信

`dist/` の内容を静的ホスティングへ配信できます。リンクは相対パスなので、GitHub Pagesのリポジトリ配下にも対応します。公開ソースの管理先はGitHub。公開配信先・反映状況は作業完了時に案内します。`dist/` は生成物なのでGit管理から除外しています。

多言語化時は `content/ja.json`、`content/en.json` としてデータを分け、言語別の出力先を生成する方針です。現状の言語は日本語であり、ENは準備中の表示です。

## 将来のDiscord更新連携

1. Botで下書きを受け付け、公開用の文章と非公開の運営記録を分離。
2. 承認者が文章・写真・日時・実施状態を確認。
3. 承認済みの公開データだけを専用ブランチに書き込み、PRを作成。
4. スキーマと内部リンクを検査してプレビュー。
5. マージ後に静的サイトをビルド・公開。履歴と差し戻しはGitHubで管理。

この連携は設計案です。BotトークンやGitHub書込資格情報をブラウザに置かないでください。
